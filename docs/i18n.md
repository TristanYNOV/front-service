# Internationalisation

Action Board utilise Transloco pour l'interface front avec deux langues supportees :

- `fr` : langue par defaut et fallback.
- `en` : langue secondaire.

Le choix utilisateur est stocke dans le cookie `app_lang` pendant un an. Les seules valeurs acceptees sont `fr` et `en`; toute autre valeur est ignoree et l'application revient au francais.

## Ajouter une cle de traduction

1. Ajouter la cle dans `src/assets/i18n/fr.json`.
2. Ajouter la meme cle au meme emplacement dans `src/assets/i18n/en.json`.
3. Utiliser la cle dans le template avec le pipe Transloco :

```html
{{ 'actions.save' | transloco }}
```

Pour une traduction avec parametre :

```html
{{ 'welcome.title' | transloco: { pseudo: userPseudo } }}
```

## Ajouter une langue

1. Creer `src/assets/i18n/<lang>.json`.
2. Ajouter la valeur dans `SUPPORTED_LANGS` et dans la liste affichee par `LanguageService`.
3. Ajouter la langue dans la configuration `availableLangs` de Transloco dans `src/app/app.config.ts`.
4. Verifier que le cookie `app_lang` n'accepte que les langues supportees.

## Notifications

Les notifications applicatives passent par `NotificationService`, qui traduit les messages et positionne les snackbars en haut a droite.

```ts
this.notifications.notifySuccess('notifications.panelSaved');
```

Les messages techniques ou issus de donnees utilisateur ne doivent pas etre traduits automatiquement.
